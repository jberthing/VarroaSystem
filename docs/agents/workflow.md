# Workflow and Handoff

## Scope
- Keep changes focused on the requested task.
- Avoid opportunistic refactors unless explicitly requested.
- Use the shared design system (tokens, `page-intro`, chips, stacked tables, etc.) when adjusting UI, and keep new work consistent with it.

## Completion Output
When finishing, include:
- What changed
- Why it changed
- Commands run and results
- Follow-ups or known limitations
- Confirmation that any new/updated UI copy is reflected in all locale files (`da/en/de`)
